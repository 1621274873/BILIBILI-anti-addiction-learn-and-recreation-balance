# Security policy

The extension is intended to process the current Bilibili page and local playback state only. It requests narrowly scoped site access, stores aggregates in Chrome local storage, and does not intentionally make external requests.

To report a security issue, use GitHub's private vulnerability reporting for this repository if it is enabled. Do not include account identifiers, cookies, private browsing data or unredacted watch history in a public issue. If private reporting is unavailable, first open a minimal issue asking for a private contact channel; do not publish exploit details there.

Security reports are reviewed on a best-effort basis. No response or fix timeline is guaranteed.
