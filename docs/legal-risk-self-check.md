# 法律与平台协议风险自检表

基于 0.3.1 实际代码；当前只有悬浮计时、每日限额及连续娱乐 25 分钟提醒，没有信息流卡片隐藏。连续提醒仅增加一份本地计时快照（秒数和最近上报时间），不增加权限或平台请求。未核验平台协议最新文本，不把特定条款编号或风控结果作为已证实事实。

| 风险点 | 为什么相关 | 你的插件是否触碰 | 如触碰，如何降级或移除 |
|---|---|---|---|
| 视频广告屏蔽类不正当竞争 | 屏蔽商业展示可能影响平台利益 | 否。无广告选择器、卡片隐藏、拦截或播放器操作 | 当前无须删除；不增加广告匹配规则 |
| B站协议对自动化/脚本获取数据的限制 | 内容脚本读取页面和插入界面仍是自动处理页面的行为 | 部分。只读当前页面已加载的标签、标题和媒体状态，添加自建 Shadow DOM | 已限制为单一主站和当前页面，无平台 API、遍历、自动点击；进一步移除需删除 manifest 的 content_scripts 和站点权限，同时放弃自动主题及自动播放计时 |
| Chrome「有限使用」与披露 | 本地行为数据也需要限定用途并与商店说明一致 | 是。保存时长和少量设置 | 已删除视频元数据的持久化，按 PRIVACY.md 披露；公开发布前填写真实数据用途表单和隐私政策 URL，自用无须商店提交 |
| 个人信息/隐私 | 日期和时长在个人浏览器中可能关联使用者，未上传不等于不构成个人信息 | 部分。保存本地行为统计，不保存账号、UID、Cookie 或视频历史 | 已提供暂停和二次确认清理，保留最近 30 个自然日，不上传不同步；进一步降级可只在页面内存计时并移除 storage 权限及跨天统计 |
| 对平台青少年保护机制的干扰 | 改写身份、限制或保护提示会改变平台保护行为 | 否。不读取或改写相关状态，不控制平台播放与提示 | 当前无须删除；不增加绕过限制或修改年龄状态的功能 |
| 悬浮窗对页面操作的影响 | 独立界面可能遮挡内容，平台也可以发现新节点 | 部分。页面右下角有扩展自建节点 | 已支持拖动、方向键移动、折叠与全屏隐藏；若不接受页面覆盖，可移除 floating-panel.js 及挂载调用，仅保留工具栏弹窗 |

当前代码减少平台互动与数据留存，但不能保证不封号，也不表示平台批准该扩展。
